# ClothSwap – Clothing Exchange & Swap Marketplace

## Project Overview

ClothSwap is a web-based clothing exchange platform that allows users to list, browse, and exchange pre-owned clothing items. The platform encourages sustainable fashion by promoting clothing reuse and reducing textile waste.

## Features

- User registration and login
- Browse available clothing items
- Add and manage clothing listings
- Send and accept swap requests
- View swap history
- User-to-user messaging
- Value-based swap suggestions
- Location-based matching

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Install backend dependencies

```bash
cd backend
npm install
```

### 3. Start the backend

```bash
npm start
```

### 4. Install frontend dependencies

Open another terminal:

```bash
cd frontend
npm install
```

### 5. Start the frontend

```bash
npm run dev
```

Open the local URL displayed in the terminal.
